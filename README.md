# OpenMAIC — корпоративная сборка

Форк [THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC), адаптируемый под
развёртывание в закрытом контуре: локальная модель через OpenAI-совместимый
эндпойнт, обратный прокси nginx, домен Active Directory, интерфейс на русском
языке, порядка десяти одновременных пользователей.

Продукт остаётся тем же: генерация интерактивного урока по текстовому запросу и
его воспроизведение в «классе» — слайды, закадровая речь, доска, квизы,
проектная работа, обсуждение нескольких агентов.

## Чем эта сборка отличается от апстрима

| | |
| --- | --- |
| **Бренд** | Название, палитра, шрифты, логотипы задаются в `lib/brand/brand-config.ts` и файлах `public/brand/`. В компонентах нет зашитых названий и цветов. См. [`docs/branding.md`](docs/branding.md). |
| **Язык** | Интерфейс — русский по умолчанию, английский как запасной. Остальные локали апстрима удалены. Язык интерфейса задаёт и язык генерируемого курса. |
| **Внешние ресурсы** | KaTeX, воркер pdf.js, шрифты и прочая статика вендорятся в `public/vendor/` на сборке. В рантайме обращений к CDN нет — код работает без интернета. |
| **Апстрим-артефакты** | Материалы публичного проекта (шаблоны issue, триаж, публикация в npm/ClawHub, сайт документации, демо-GIF, ссылки на сообщества) удалены — в закрытом контуре они ведут в никуда. |
| **Дальше по плану** | Слой идентичности, разделение данных между пользователями, Kerberos/SPNEGO за nginx — см. `docs/plan/`. |

## Быстрый старт

Нужны Node.js >= 22.19.0 и pnpm.

```bash
pnpm install                 # собирает workspace-пакеты и вендорит статику
cp .env.example .env.local   # заполнить эндпойнт модели и ключи
pnpm dev                     # http://localhost:3000
```

Продакшен-сборка:

```bash
pnpm build
pnpm start
```

Секреты живут только в переменных окружения и никогда — в переменных с
префиксом `NEXT_PUBLIC_`: они попадают в клиентский бандл.

Без `NEXT_PUBLIC_PERSISTENCE` приложение хранит данные в браузере и не требует
базы. Серверное хранение включается PostgreSQL-провайдером — см. `.env.example`.

## Проверки

CI гоняет то же самое; локально дешевле поймать раньше.

```bash
pnpm format                  # prettier --write
pnpm lint --fix
npx tsc --noEmit
pnpm check:i18n-keys         # ключи локалей + формы множественного числа
pnpm check:brand-contrast    # WCAG-контраст токенов темы
pnpm check:brand-fonts       # покрытие кириллицы объявленными шрифтами
pnpm test                    # vitest
pnpm test:e2e                # playwright
```

Правила, которые стоит держать в голове при правках:

- любой текст, видимый пользователю, идёт через i18n — строк в коде не зашиваем;
- добавили или переименовали переменную окружения — обновите `.env.example` в
  том же коммите, с пометкой, читается она на сборке или в рантайме;
- сообщения коммитов — [Conventional Commits](https://www.conventionalcommits.org/):
  `feat(scope): ...`, `fix(scope): ...`, `docs(scope): ...`.

## Ключевые узлы

- **Конвейер генерации** (`@openmaic/generation`) — два этапа: план урока →
  содержимое сцен.
- **Рантайм агента** (`lib/server/agent-runtime/`) — сессии в PostgreSQL с
  арендой исполнения, возобновлением и корректировкой хода.
- **Слой хранения** (`@openmaic/storage`) — сменные хранилища документов,
  рантайма, KV, ассетов, сессий агента, материалов и пользовательских навыков.
- **Оркестрация** (`lib/orchestration/`) — автомат LangGraph, управляющий
  очередью реплик агентов.
- **Воспроизведение** (`lib/playback/`) — автомат, ведущий урок и живое
  взаимодействие.
- **Движок действий** (`lib/action/`) — исполняет более 28 типов действий (речь,
  рисование и текст на доске, диаграммы, подсветка, лазер …).
